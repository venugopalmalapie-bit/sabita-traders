# Sabita Traders – website

Website of Sabita Traders, authorised John Deere tractor dealer, Berhampur (Ganjam, Odisha).

- Live (test): https://venugopalmalapie-bit.github.io/sabita-traders/
- Plain HTML, no build step on GitHub: every page is a ready `.html` file, images are in `images/`.
- The test version is hidden from search engines (`noindex`). See `SEO-LAUNCH-CHECKLIST.txt` before going public.
